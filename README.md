# SMB Bruteforce
Python port of the original SMB Bruteforce batch script.

⚠️ Authorized use only — run against systems you own or have permission to test.

# Setup
pip install impacket
Usage
python smb_bruteforce.py
Enter the target IP, username, and password list when prompted.

Password list = plain text file, one password per line.

*Notes*
Success → prints the matching password
List exhausted → prints Password not Found :(
